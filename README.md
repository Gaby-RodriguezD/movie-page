# Cinematic Platform Dashboard (Movie Mock Page)
An immersive catalog landing page to demonstrate modern front-end layout, structured HTML, CSS and Javascript implementation. This project is made to mimic a video streaming recommendation platform while exploring interactive and visual interesting functionalities.

Demo Link: https://gaby-rodriguezd.github.io/movie-page/

##Key Features:
* Immersive Media Layout: Structured a fluid display layout capable of handling heavy visual assets without breaking alignment metrics.
* Interactive UI Components: Customized visual hover states, active transitions and responsive navigation yo enhance front-end yser engagement.
* Fluid Breakpoints: Designed responsive rules ensuring mobile and desktop presentation across different screen sizes.

##Tech Stack & Architecture:
* Structure: HTML5.
* Styling: CSS.
* Methodology: Responsive web design with fluid layout components.

  ## Structure:
  *| index.html #Main movie catalog display.
  *| css.html #Main display styling components.
  *| specific-movie.html #An inidivdual document for every movie that carries all it's information.
  *| specific-movie.css #Every movie specific styling that help implement it's interactive components.
